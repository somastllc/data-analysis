## Overview

Your inbox quietly moved a message to spam this morning. Nobody wrote a rule naming that exact sender. Something learned what spam looks like, from millions of messages other people marked before you. **Data science** and **machine learning** are often mentioned together, but they are not the same thing.

### What is data science?

**Data science** combines statistics, programming, domain knowledge, and data analysis to extract insights and build data-driven solutions.

Data scientists often work on problems such as:

- Forecasting demand
- Detecting fraud
- Recommending products
- Analyzing complex datasets

Data science usually goes beyond basic reporting. It may involve advanced analysis, experimentation, and model building.

### What is machine learning?

**Machine learning (ML)** is a branch of artificial intelligence where computers learn patterns from data instead of being explicitly programmed for every rule.

Examples:

- Email spam detection
- Movie recommendations
- Voice recognition
- Image classification

Instead of writing every rule manually, the system learns from examples.

### How they relate

Machine learning is one tool within data science.

- **Data science** is the broader field
- **Machine learning** is a method data scientists use for prediction and automation

Not every data science project requires machine learning. Some problems can be solved with simpler analysis.

### Example

A music app wants to recommend songs.

- A **data analyst** might report which genres are most popular
- A **data scientist** might build a recommendation model using listening history
- The **machine learning model** learns user preferences and suggests new songs

## Key Terms

| Term | Definition |
|---|---|
| **Data science** | A field that uses data, statistics, and programming to solve complex problems |
| **Machine learning** | A method where systems learn patterns from data |
| **Model** | A system trained to make predictions or decisions from data |
