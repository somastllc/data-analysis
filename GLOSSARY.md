# Glossary

Every term defined in this course, in one place. The chapter column shows where the term is introduced.

The vocabulary here is what the rest of data work assumes you already have.

| Term | Definition | Introduced in |
|---|---|---|
| **Access control** | Limiting who can see or use specific data | Ch 4 - Data Ethics and Privacy |
| **Accountability** | Responsibility for the outcomes of data use | Ch 4 - Data Ethics and Privacy |
| **Accuracy** | Whether data values are correct | Ch 1 - What Is Data? |
| **Analytics** | The use of data to find patterns and support decisions | Ch 2 - The Data Ecosystem |
| **Anonymization** | Removing details that could identify a specific person | Ch 4 - Data Ethics and Privacy |
| **Archiving** | Moving data out of everyday systems into slower, cheaper storage | Ch 1 - What Is Data? |
| **Bias** | Systematic unfairness in data or analysis | Ch 4 - Data Ethics and Privacy |
| **Big data** | Data at a scale that ordinary tools and methods can no longer handle | Ch 1 - What Is Data? |
| **Business intelligence (BI)** | Tools and practices for reporting and monitoring business performance | Ch 2 - The Data Ecosystem |
| **Categorical data** | Data that groups items into labels or categories | Ch 1 - What Is Data? |
| **Churn** | When customers stop using a product or service | Ch 5 - Conclusion |
| **Competitive advantage** | An edge that helps an organization perform better than others | Ch 1 - What Is Data? |
| **Completeness** | Whether required data is present | Ch 1 - What Is Data? |
| **Consent** | Permission to collect or use data | Ch 4 - Data Ethics and Privacy |
| **Consistency** | Whether data follows the same format and rules | Ch 1 - What Is Data? |
| **CSV** | A plain-text format for tabular data | Ch 1 - What Is Data? |
| **Dashboard** | A visual display of key metrics and charts | Ch 3 - Data in the Real World |
| **Data** | Raw facts, measurements, or observations | Ch 1 - What Is Data? |
| **Data analysis** | The process of examining data to find patterns and answer questions | Ch 2 - The Data Ecosystem |
| **Data Analyst** | A professional who analyzes data to answer business questions | Ch 2 - The Data Ecosystem |
| **Data ecosystem** | The connected roles, tools, and processes around data | Ch 2 - The Data Ecosystem |
| **Data Engineer** | A professional who builds data systems and pipelines | Ch 2 - The Data Ecosystem |
| **Data engineering** | Building systems to collect, store, and prepare data | Ch 2 - The Data Ecosystem |
| **Data ethics** | Principles for using data responsibly and fairly | Ch 4 - Data Ethics and Privacy |
| **Data format** | The way data is stored or shared | Ch 1 - What Is Data? |
| **Data governance** | Policies and processes for managing data responsibly | Ch 4 - Data Ethics and Privacy |
| **Data lifecycle** | The full path data follows from creation to deletion | Ch 1 - What Is Data? |
| **Data minimization** | Collecting only the data a stated purpose actually requires | Ch 4 - Data Ethics and Privacy |
| **Data pipeline** | A workflow that moves data from its source to its final use | Ch 2 - The Data Ecosystem |
| **Data quality** | How fit data is for its intended use | Ch 1 - What Is Data? |
| **Data retention** | How long data is kept before it is deleted | Ch 4 - Data Ethics and Privacy |
| **Data science** | A field that uses data, statistics, and programming to solve complex problems | Ch 2 - The Data Ecosystem |
| **Data Scientist** | A professional who uses advanced methods to extract insights and build models | Ch 2 - The Data Ecosystem |
| **Data security** | Protecting data from unauthorized access or loss | Ch 4 - Data Ethics and Privacy |
| **Data source** | Where data originally comes from | Ch 1 - What Is Data? |
| **Data warehouse** | A centralized system designed for analysis and reporting | Ch 2 - The Data Ecosystem |
| **Data-driven** | Using data to guide actions and decisions | Ch 1 - What Is Data? |
| **Database** | A structured system for storing and retrieving data | Ch 2 - The Data Ecosystem |
| **Descriptive analytics** | Summarizes what already happened | Ch 2 - The Data Ecosystem |
| **Diagnostic analytics** | Explains why something happened | Ch 2 - The Data Ecosystem |
| **Domain knowledge** | Understanding how a particular industry or area works | Ch 2 - The Data Ecosystem |
| **Fairness** | Avoiding unjust harm in data-driven decisions | Ch 4 - Data Ethics and Privacy |
| **Feedback loop** | When a system's own decisions become the data that trains its future decisions | Ch 4 - Data Ethics and Privacy |
| **Garbage in, garbage out (GIGO)** | Poor input data produces poor output, even when the calculation or tool works correctly | Ch 1 - What Is Data? |
| **Information** | Data that has been organized to convey meaning | Ch 1 - What Is Data? |
| **Insight** | A meaningful conclusion, supported by data, that helps guide a decision | Ch 1 - What Is Data? |
| **Machine learning** | A method where systems learn patterns from data | Ch 2 - The Data Ecosystem |
| **Machine Learning Engineer** | A professional who puts models into production and keeps them running | Ch 2 - The Data Ecosystem |
| **Misleading visualization** | A chart that is factually correct but creates a false impression | Ch 4 - Data Ethics and Privacy |
| **Model** | A system trained to make predictions or decisions from data | Ch 2 - The Data Ecosystem |
| **Onboarding** | The first experience new users have with a product | Ch 5 - Conclusion |
| **Predictive analytics** | Estimates what may happen in the future | Ch 2 - The Data Ecosystem |
| **Prescriptive analytics** | Recommends actions based on analysis | Ch 2 - The Data Ecosystem |
| **Primary data** | Data collected firsthand for a specific purpose | Ch 1 - What Is Data? |
| **Privacy** | The right to control personal information | Ch 4 - Data Ethics and Privacy |
| **Process** | Turning collected data into the form the next stage needs | Ch 1 - What Is Data? |
| **Proxy variable** | A field that indirectly stands in for information you did not measure | Ch 4 - Data Ethics and Privacy |
| **Purpose limitation** | Using data only for the purpose it was collected for | Ch 4 - Data Ethics and Privacy |
| **Qualitative data** | Descriptive data, often in words or categories | Ch 1 - What Is Data? |
| **Quantitative data** | Numeric data that can be measured or counted | Ch 1 - What Is Data? |
| **Query** | A request to retrieve data from a database | Ch 3 - Data in the Real World |
| **Regulation** | A legal rule governing data collection and use | Ch 4 - Data Ethics and Privacy |
| **Sampling bias** | When data does not represent the full population fairly | Ch 4 - Data Ethics and Privacy |
| **Secondary data** | Data collected by others and reused for a new purpose | Ch 1 - What Is Data? |
| **Semi-structured data** | Data with some organization, such as JSON, but not a fixed table | Ch 1 - What Is Data? |
| **Spreadsheet** | A grid-based tool for organizing and calculating data | Ch 3 - Data in the Real World |
| **Structured data** | Data organized in rows, columns, or tables | Ch 1 - What Is Data? |
| **Training** | The process through which a machine-learning system learns patterns from past examples | Ch 2 - The Data Ecosystem |
| **Transferable skills** | Skills that can be used in many jobs or industries | Ch 3 - Data in the Real World |
| **Transform** | Reshaping or preparing data for analysis | Ch 2 - The Data Ecosystem |
| **Transparency** | Openness about data collection and use | Ch 4 - Data Ethics and Privacy |
| **Unstructured data** | Data without a fixed format, such as text or images | Ch 1 - What Is Data? |
| **Velocity** | How fast new data arrives | Ch 1 - What Is Data? |
| **Version control** | Tracking changes to files over time | Ch 3 - Data in the Real World |
| **Volume** | How much data there is | Ch 1 - What Is Data? |
